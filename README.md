# Book Explorer Web App (Frontend Phase 1 Capstone)

> A responsive, interactive, and API-powered web application built with HTML5, Tailwind CSS, and modular JavaScript (ES6).

## 🚀 Project Overview
This project brings together core frontend development skills, simulating a real-world web application workflow from responsive UI design to dynamic asynchronous data fetching and local state management.

## ✨ Key Features & Labs Addressed
- **Lab 1 (Responsive Layouts):** Built mobile-first using Tailwind CSS components, navigation bars, and flexible CSS grid layouts.
- **Lab 2 (DOM Interactivity & Modules):** Created a dedicated Favorites page and organized JavaScript logic using ES6 modules (`favorites.js`) and browser `localStorage` for state persistence.
- **Lab 3 (Async API Integration):** Fetched live book records asynchronously via `fetch` and `async/await` from the Open Library API, complete with search bars and loading states.
- **Lab 4 (GitHub Collaboration):** Managed tasks, feature branching, and bug tracking using professional Git workflows.
- **Multi-Page Navigation:** Seamlessly browse between **Home**, **Favorites**, and **About** views.

## 🛠️ Technologies Used
- **HTML5:** Semantic markup structure.
- **Tailwind CSS:** Utility-first styling and responsive grid design.
- **JavaScript (ES6 Modules):** Modular code architecture for scalability.
- **Open Library API:** External public REST API for live data retrieval.
