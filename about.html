About Book Explorer

Book Explorer is a responsive web application built for the Frontend Phase 1 Capstone.

  • Layout & Design: Built using HTML5 and Tailwind CSS for mobile-first responsiveness.
  • Architecture: Uses ES6 JavaScript modules for clean and maintainable code separation.
  • API Integration: Fetches live book records asynchronously via `async/await` and `fetch`.
  • State Persistence: Uses browser `localStorage` so user favorites remain saved across refreshes.
